## 数据库设计文档

本文以 [sky.sql](./sky.sql) 中的建表语句和演示数据为准。数据库名为 `sky_take_out`，共包含 11 张表；初始化脚本会重建这些表并写入演示数据。

表之间通过 ID 进行逻辑关联，当前建表脚本未创建物理外键约束。

| 序号 | 数据表名      | 中文名称       |
| ---- | ------------- | -------------- |
| 1    | employee      | 员工表         |
| 2    | category      | 分类表         |
| 3    | dish          | 菜品表         |
| 4    | dish_flavor   | 菜品口味表     |
| 5    | setmeal       | 套餐表         |
| 6    | setmeal_dish  | 套餐菜品关系表 |
| 7    | user          | 用户表         |
| 8    | address_book  | 地址表         |
| 9    | shopping_cart | 购物车表       |
| 10   | orders        | 订单表         |
| 11   | order_detail  | 订单明细表     |

### 1. employee

| 字段名      | 数据类型     | 说明         | 备注                        |
| ----------- | ------------ | ------------ | --------------------------- |
| id          | bigint       | 主键         | 自增                        |
| name        | varchar(32)  | 姓名         | 非空                        |
| username    | varchar(32)  | 用户名       | 非空，唯一                  |
| password    | varchar(128) | 密码哈希     | 非空，保存完整 Argon2id 哈希 |
| phone       | varchar(11)  | 手机号       | 非空                        |
| sex         | varchar(2)   | 性别         | 非空                        |
| id_number   | varchar(18)  | 身份证号     | 非空                        |
| status      | int          | 账号状态     | 非空，默认1；0禁用 1启用     |
| create_time | datetime     | 创建时间     |                             |
| update_time | datetime     | 最后修改时间 |                             |

### 7. user

user表为用户表，用于存储C端用户的账号和个人资料。`account` 为登录账号，`username` 为用户名，`name` 为真实姓名；登录账号具有唯一约束，用户名允许重复。具体表结构如下：

| 字段名      | 数据类型     | 说明         | 备注                        |
| ----------- | ------------ | ------------ | --------------------------- |
| id          | bigint       | 主键         | 自增                        |
| account     | varchar(32)  | 登录账号     | 非空，唯一                  |
| password    | varchar(128) | 密码哈希     | 非空，保存完整 Argon2id 哈希 |
| username    | varchar(32)  | 用户名       | 非空，允许重复              |
| name        | varchar(32)  | 真实姓名     | 可为空                      |
| status      | int          | 账号状态     | 非空，默认1；0禁用 1启用     |
| phone       | varchar(11)  | 手机号       | 可为空                      |
| sex         | varchar(2)   | 性别         | 可为空                      |
| id_number   | varchar(18)  | 身份证号     | 可为空                      |
| avatar      | varchar(500) | 用户头像路径 | 可为空                      |
| create_time | datetime     | 注册时间     | 可为空，由业务代码写入      |
| update_time | datetime     | 最后修改时间 | 可为空，由业务代码写入      |

订单、地址和购物车继续通过 `user.id` 关联用户，不依赖登录账号或用户名。

### 演示账号与密码

初始化脚本中的演示账号如下，账号状态均为启用：

| 所属表   | 账号字段 | 演示账号                               | 默认密码 |
| -------- | -------- | -------------------------------------- | -------- |
| employee | username | admin、staff                           | 123456   |
| user     | account  | demo01、demo02、demo03、demo04、demo05   | 123456   |

员工和用户演示数据的密码哈希采用后端 `PasswordHasher` 的同一编码方案，校验时使用该组件的 `matches` 方法。当前编码算法为 Argon2id，参数为内存 19456 KiB（19 MiB）、迭代次数 2、并行度 1、随机盐长度 16 字节、哈希长度 32 字节。

数据库保存包含算法、参数、盐和哈希的完整编码字符串，不保存明文密码，也无需单独增加盐字段。每个账号使用独立随机盐，因此默认密码相同，保存的哈希值仍然不同。
